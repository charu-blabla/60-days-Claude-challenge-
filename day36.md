# Day 36 – Cognitive Pattern Explorer

## Overview

On Day 36 of the ABTalks 60-Day Claude Challenge, I built the Cognitive Pattern Explorer,
an interactive HTML application generated using Claude. The application helps users understand 
how different mental states influence thinking, decision-making, and reflection through engaging activities.

## Key Learnings

- AI can generate interactive educational applications from detailed prompts.
- Mental state significantly affects decision-making and cognitive patterns.
- Reflection tools help identify personal thinking tendencies.
- Interactive learning experiences improve engagement and understanding.
- Structuring prompts clearly leads to higher-quality AI-generated applications.

Reflection

This project demonstrated how AI can be used to create meaningful self-reflection tools.
Comparing my responses in Calm Mode and Stress Mode highlighted how context and emotional 
state can influence decisions. It was an interesting exercise that combined AI-generated 
development with personal learning and reinforced the importance of thoughtful prompting.
