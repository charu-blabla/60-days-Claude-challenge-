# Day 17: Vehicle Cost Analysis Dashboard

## Overview

Built a Vehicle Cost Analysis Dashboard using Claude by 
processing vehicle data from a CSV dataset and generating an interactive HTML dashboard.
The dashboard provides insights into fuel costs, maintenance expenses, environmental impact,
and E85 fuel economics through visual analytics and KPI metrics.

## Key Learnings

- Converting raw CSV data into actionable insights

- Using AI prompts to generate complete HTML applications

- Understanding KPI cards and dashboard design principles

- Exploring fuel cost and maintenance cost comparisons

- Analyzing environmental impact metrics

- Working with SVG charts, gauges, and data visualizations


## Reflection

This project showed me how AI can accelerate the creation of data-driven applications.
Instead of manually building every component, I learned how effective prompting can 
generate dashboards that combine analysis, visualization, and user-friendly design.
It was a great introduction to turning datasets into meaningful business insights.
