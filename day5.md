# Day 5 - Context Engineering

## Objective
Understand how context influences AI-generated outputs and compare results from a generic prompt versus a context-rich prompt.

## Activity
- Generated a roadmap using a generic prompt.
- Generated another roadmap using a prompt containing personal details, goals, and background information.
- Compared both outputs to analyze the impact of context.

## Observation

### Output 1: Generic Prompt
- Broad and general roadmap.
- Applicable to a wide audience.
- Less personalized guidance.

### Output 2: Context-Rich Prompt
- More relevant and personalized roadmap.
- Better aligned with goals and experience.
- More actionable recommendations.

## Key Learning
Context plays a crucial role in prompt engineering. The more relevant information provided to the AI, the more tailored and useful the response becomes.

## Reflection
Context Engineering helps transform AI outputs from generic responses into personalized and goal-oriented solutions.
