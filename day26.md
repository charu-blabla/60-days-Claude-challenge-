# Day 26 – Prior Authorization Workflow Simulator

## Overview

For Day 26, I built and explored a **Prior Authorization Workflow Simulator** 
using an AI-generated HTML application. The simulator demonstrates how healthcare 
providers submit prior authorization requests to insurance payers, including the required 
documentation, review process, and possible outcomes such as approval, pending, denial, and appeal.

## Key Learnings

* Learned the complete prior authorization workflow in healthcare.
* Understood the importance of attaching all required documents before submitting a request.
* Explored different authorization outcomes, including approval, pending, denial, and appeal.
* Observed how the journey tracker and elapsed days help visualize the progress of a request.
* Gained more experience using AI to generate interactive web applications from detailed prompts.

## Reflection

This project introduced me to a real-world healthcare workflow that I wasn't familiar with before.
It showed me how AI can be used not only to generate code but also to create educational simulations 
that explain complex processes in an interactive way. Working through different scenarios helped me 
better understand the workflow while reinforcing the value of clear documentation and thoughtful prompt engineering.
