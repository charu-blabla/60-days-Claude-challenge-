# Day 33 – Media Integrity Analyzer

## Overview

Today, I built an interactive Media Integrity Analyzer using AI.
The application helps users recognize misleading headlines, detect
emotional manipulation, and understand how media integrity can be evaluated through interactive challenges.

## Key Learnings

- Identified common characteristics of misleading headlines.
- Learned how emotional language can influence readers.
- Understood how AI can assist in evaluating media credibility.
- Explored interactive dashboards and real-time metric updates using HTML, CSS, and JavaScript.
- Improved prompt engineering skills by generating a complete web application with AI.

## Reflection

This project strengthened my understanding of media literacy while demonstrating how AI
can be used to build educational, interactive web applications. It also reinforced the importance
of verifying information before accepting or sharing it.
