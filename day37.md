# Day 37 – Task Compass

## Overview
Built an interactive HTML application called **Task Compass** using Claude.
The application simulates workplace task management scenarios to strengthen organizational thinking, task ownership, and collaboration skills.

## Objectives
- Generate a complete HTML application using AI.
- Understand task ownership in different workplace environments.
- Practice efficient task routing.
- Improve collaboration and organizational decision-making.


## Reflection
This project highlighted the importance of assigning clear ownership,
routing tasks efficiently, and collaborating effectively within a team.
Replaying the simulation with a different workplace type helped me understand how organizational 
structures can influence decision-making and workflow management.
