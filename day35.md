# Day 35 - Prompt Puzzle

## Overview
Build an interactive Prompt Puzzle HTML application using Claude and strengthen prompt engineering skills through practical challenges.

## Key Learnings
- Prompt wording has a significant impact on AI responses.
- Providing clear context and constraints improves output quality.
- Iterating on prompts leads to more accurate and useful results.
- Evaluating prompt performance helps identify areas for improvement.

## Reflection
Today's challenge showed me that prompt engineering is an iterative process.
Even small changes in wording or structure can produce noticeably different results. 
Replaying the challenges with another domain helped me understand how prompts can be adapted 
for different use cases while maintaining clarity and effectiveness. This exercise improved my
confidence in designing better prompts for AI applications.
