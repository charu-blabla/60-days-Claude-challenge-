# Day 20 – Face Puzzle Game

## Overview

A responsive Face Puzzle Game that captures an
image using the webcam, converts it into a sliding puzzle, 
supports multiple difficulty levels, and tracks time, moves,
and leaderboard scores.

## Key Learnings

- Working with the Web Camera API.
  
- Building interactive drag-and-drop puzzle mechanics.
  
- Managing game state with JavaScript.

- Creating responsive desktop and mobile interactions.

## Reflection
This project gave me hands-on experience with browser APIs
and interactive game logic. It also reinforced the importance of
testing user interactions across different devices and screen sizes.
