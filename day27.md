# Day 27 – Prior Authorization Story Simulator

## Overview

On Day 27, I created an interactive Prior Authorization Story Simulator using Claude.
The simulator presents Rahul's healthcare journey through eight chapters, where Priya 
explains each stage of the prior authorization process. Users make choices throughout the story,
observe their progress with a progress bar, and can replay the experience to explore different dialogue paths.

## Key Learnings

- Improved prompt engineering skills using Claude
- Learned how interactive branching stories are structured
- Understood the prior authorization workflow through storytelling
- Gained more experience working with HTML-based applications
- Practiced documenting projects and maintaining a consistent GitHub learning log

## Reflection

This project demonstrated how AI can quickly generate interactive educational applications.
It also reinforced the importance of testing, documenting work, and exploring different user paths to better understand an application's behavior.
