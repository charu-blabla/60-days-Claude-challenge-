# Day 8 – Building an AI-Powered Environmental Health Analyzer Dashboard

## Overview

On Day 8, I explored how AI can be used to generate complete web applications. 
Using Claude, I created an Environmental Health Analyzer Dashboard, generated 
a downloadable HTML application, and tested its interactive features such as filters and charts.

## What I Learned

- How detailed prompts can guide AI in building functional applications.

- The importance of prompt clarity for generating structured outputs.

- How AI-generated dashboards can simplify data analysis and visualization.

- The value of testing and validating AI-generated applications.


## Key Features

- Interactive dashboard interface

- Data visualization through charts

- Dynamic filtering options

- Standalone downloadable HTML application


## Reflection

This project demonstrated that AI can do much more than generate
text—it can help create practical, interactive tools. Building and testing 
a dashboard gave me a better understanding of how prompt engineering can be 
applied to real-world application development.
