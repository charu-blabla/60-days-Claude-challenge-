# Day 28 – Hospital Admission Readiness Simulator

## Overview

Built an interactive Hospital Admission Readiness Simulator that models the hospital admission workflow.
The application evaluates admission readiness by considering provider information, diagnosis, admission type,
prior authorization status, documentation completeness, insurance verification, bed availability, and clinical readiness.

## Key Learnings

- Learned how hospital admission readiness is assessed.
- Explored the impact of Prior Authorization on patient admissions.
- Simulated documentation, insurance, and clinical risk management.
- Built an interactive HTML application with AI-assisted development.
- Improved understanding of healthcare workflow automation and decision support systems.

## Reflection

This project demonstrated how multiple operational and clinical factors influence hospital admissions. 
Building the simulator strengthened both my front-end development skills and my understanding of healthcare workflows. 
It also reinforced how AI can accelerate the development of educational and workflow simulation tools.
